# Exacademy course files

Download files for the Exasol Exacademy courses: datasets, lab apps and ready-made zips. Built from the course
repository with `tools/mirror/build_mirror.py`; lessons link to a tagged version, never to `main`.

| Download | Used in |
|---|---|
| `downloads/retail_mini.zip` | EXA-SQL-100 *The Exasol flavour of SQL* and later courses (schema RETAIL) |
| `downloads/exa-gs-100-lab.zip` | EXA-GS-100 *Up and running with Exasol*: the taxi zone file for lesson 3 and the New Year's Eve dashboard for lesson 5 (bundle v1.2.0) |
| `downloads/exa-gs-190-lab.zip` | EXA-GS-190 *Capstone: build your own Exasol dashboard*: the self-check for lesson 2 and the dashboard starter for lesson 3 (bundle v1.3.0) |

Dataset sources and licences: see the README in each folder under `content/datasets/`.
