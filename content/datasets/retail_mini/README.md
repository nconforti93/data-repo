# retail_mini

One year (16 Mar 2014 – 15 Mar 2015) of receipts from a generated German supermarket chain. Loaded into
schema `RETAIL` in EXA-GS-100 and used by EXA-SQL-100 and later courses.

| File | Rows | One row per |
|---|---|---|
| `SALES.csv` | 100,001 | receipt |
| `SALES_POSITIONS.csv` | 1,047,037 | line on a receipt (31,464 cancelled) |
| `ARTICLE.csv` | 5,476 | product (German names, English product groups) |
| `MARKETS.csv` | 100 | store, with longitude/latitude |
| `CITIES.csv` | 93 | city, with latitude/longitude |
| `DIM_DATE.csv` | 356 | day with sales |

`retail_mini.sql` creates the tables. Load with
`exapump upload -p starter-kit -t RETAIL.<TABLE> <TABLE>.csv` (header row, comma-separated, UTF-8, LF).

**Origin and licence:** generated by Exasol for training (old Exacademy `retail_mini`, reworked 2026-11-18:
header rows added, line endings normalised, always-empty columns LOYALTY_ID, VOUCHER_ID and TMP_OLD_NR
dropped). Free to use for Exasol training.

**Download for learners:** mirrored by `tools/mirror/build_mirror.py` to the public repository
<https://github.com/nconforti93/data-repo> (pinned by tag, e.g. `downloads/retail_mini.zip` at `v1.0.0`).
